# 弹球工坊

一个用于口播/背景视频的弹球演示工具。当前已完成：核心玩法、皮肤系统、图片上传。

## 开发

```bash
pnpm install
pnpm dev
```

## 本地服务(mac)

```bash
./scripts/install_launchd_mac.sh   # 首次(或移动过项目目录后):安装 launchd 服务
./scripts/start_mac.sh             # 启动并校验 http://127.0.0.1:5173/
./scripts/stop_mac.sh              # 停止(加 --dry-run 只预览不动进程)
```

由 launchd 托管,脚本退出后服务继续运行;开机不会自动启动。日志在 /tmp/pinball-workshop-dev.log。

## 构建

```bash
pnpm build
```

## 预览生产包

pnpm preview

## 当前能力

### 核心玩法


- 支持五种视频比例：16:9 / 9:16 / 4:3 / 3:4 / 1:1
- 球速、球径、门宽可调
- 门位置支持随机和手动（上/下/左/右）
- 随机钉子，数量和直径可调
- 球撞墙、撞钉均保持速度大小不变，仅改方向
- 碰撞后加入小角度扰动，减少固定路线造成的死局
- 进入门口后本局结束，显示用时、碰墙和碰钉统计
- 局号可见，新一局会生成新随机 seed
- 局设置在下一局生效；球速可在当前局实时调整
### 皮肤与图片
- 球、门、球场三层独立皮肤
- 球皮肤内置：经典、纯色、紫色、亮红、条纹、棋盘
- 门皮肤内置：荧光、足球门、传送门、靶门
- 球场皮肤内置：影棚、纯色、网格、波点、条纹
- 球图片圆形裁剪；门图片按门口贴合；球场图片自动铺满
- 球场图片可调节图片压暗，方便上层视频保持可读
### 录制
- 顶部“录制”按钮只捕获弹球画布，界面不会进画面
- 优先输出 H.264 MP4，浏览器不支持时回退 WebM
- 停止后自动下载

### 持久化
- 画面比例、速度、球径、门宽、门位置、钉子、皮肤会自动保存到 localStorage
- 球、门、球场图片保存在 IndexedDB，刷新后仍可用
- 可从皮肤面板单独清空某张上传图片片
